# 캐릭터 일러스트

## 1. 입력 파악
- 요청서(`requests/*.md`)가 있으면 그것을, 없으면 사용자 메시지를 기준으로 한다.
- 다음을 확정한다: 캐릭터, 스타일, 장면(포즈·표정·배경·구도), 비율, 장수.
- 캐릭터 파일이나 스타일 파일이 없으면 생성하지 말고 사용자에게 알린다.
- 스타일이 지정되지 않았으면 캐릭터 파일의 `기본 스타일`을 쓴다.

## 2. 재료 읽기
- `characters/<캐릭터>.md` 전체
- `styles/<스타일>.md` 전체
- `refs/<캐릭터>/`, `refs/styles/<스타일>/`에 이미지가 있으면 레퍼런스로 함께 넘긴다.
- 캐릭터 파일의 `소품` 중 이 장면에 등장하는 것이 있으면 `props/<소품>.md`를 읽고, 형태·색·문양을 프롬프트의 의상 다음에 넣는다. `refs/props/<소품>/`의 확정 이미지도 레퍼런스로 넘긴다.

## 3. 프롬프트 조립
아래 순서로 영어 프롬프트를 만든다. 앞에 올수록 우선순위가 높다.

1. **매체/스타일**: 스타일 파일의 핵심 키워드
2. **캐릭터 고정 외형**: 캐릭터 파일의 `고정 외형` 전부. 생략하거나 바꾸지 않는다.
3. **의상**: 요청에 의상 지정이 없으면 `기본 의상`
4. **장면**: 포즈, 표정, 행동, 구도(샷 크기·카메라 각도)
5. **배경과 조명**
6. **네거티브**: 스타일 파일의 금지 요소 + 캐릭터 파일의 `절대 금지`

캐릭터가 여러 명이면 각자의 외형을 명확히 구분해서 섞이지 않게 적는다 (예: "the girl on the left has…, the boy on the right has…").

## 4. 생성
- 사용 가능한 이미지 생성 도구로 생성한다.
- 기본 1장. 요청에 장수가 있으면 그만큼 생성한다.

## 5. 검수
생성 결과를 직접 보고 캐릭터 파일의 `체크리스트`를 하나씩 확인한다.
- 틀린 항목이 있으면 해당 부분을 프롬프트에서 더 앞으로 옮기거나 강조해서 재생성한다. 최대 2회까지.
- 그래도 틀리면 멈추고, 어떤 항목이 계속 틀리는지 사용자에게 보고한다.

## 6. 저장
`AGENTS.md`의 공통 규칙대로 `outputs/`에 저장한다. `prompt.md`에는 다음을 적는다:
- 사용한 캐릭터·스타일 파일 경로
- 최종 프롬프트 원문, 네거티브, 비율
- 검수 결과 (체크리스트 통과/실패 항목)와 재시도할 때 바꾼 내용
