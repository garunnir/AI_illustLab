## 관리 규칙

- `design.png` 또는 `design.jpeg`는 현재 확정 이미지의 사본이다. 원본 형식을 유지하며, 확정 버전 번호와 원본 경로는 같은 폴더의 `design.md`에 기록한다.
- 새 버전을 사용자가 확정하면 해당 사본·설정·이 목록을 함께 갱신한다. 이전 버전은 `_archive/outputs/`에 남긴다.
- 단순 시안 생성이나 수정 요청만으로 확정본을 바꾸지 않는다.
- 상세 설정은 해당 확정 폴더의 `settings.md`, 스타일 정의는 `confirmed/styles/`에서 관리한다. 이전 설정은 `_archive/`에 보존한다.
- 확정 이미지와 설정이 충돌하면 임의로 혼합하지 않고 불일치를 알린다.
